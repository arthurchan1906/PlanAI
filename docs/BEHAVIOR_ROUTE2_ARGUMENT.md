## 2. 为什么必须论证路2(而不是接受现状)

**路1 已排除两个"省事"的解释,只剩路2 一条干净路:**

1. **"行为有信号"≠"skill 强制有效"**:claude 与 codex **同步** 6月≈0 → 7/8月 >50%(≈53~60%);而 **codex 收不到 skill 也同步跳**。→ 提升由**工具上线+可发现性/注入**驱动,**skill 强制的边际增量没显现**。若直接宣布"skill 是有效杠杆",是把可发现性混淆为强制,违反同宇宙归因。
2. **"做了 briefing → 质量更高"是 auto 章假象**:含 `auto` 时执行组 96.3% vs 未执行组 82.7%(似正相关);排除 `auto`(仅人工)后执行组 **31.2%/22.9% vs 未执行组 38.7%/29.6%** —— **执行组反而更低**。→ 行为与人工结果**无独立正相关**;任何"执行率提升=更好"的口径都会踩进 QualityScoreValue 循环论证。

**因此**:要证明"把某行为做成强制/引导后,自发使用率真的被推高",路1 的观测数据**证不了因果**;唯一干净做法是**同 agent A/B**,让"可发现性、工具集、注入、agent"全部恒定,只变"skill 开/关"这一维。

## 3. 可行性

**可行前提(缺一不可):**
- **同 agent 做对照**:仅 claude 可做(它支持 skill 开/关);codex 无 skill 支持,不能作为对照对象。→ 样本被限到 **1 个 agent**。
- **只变 skill,其余冻结**:同一 claude 二进制 + 同一工具描述 + 同一注入路径 + 同一任务类型,仅 skill 开/关。若实验窗口内同时改工具/描述/注入,可发现性再次混入,实验作废。
- **skill_off 形态必须写死 = 文件不存在**:off 组必须是 skill **文件不存在**(对 agent 完全不可见),**不能是"存在但关闭/被禁用"**。若是后者,agent 在 open/start 提示里仍可能感知到该 skill 存在(可发现性残留),对照组被污染——届时分离的到底是"强制增量"还是"不可见增量"就说不清了。**红线:off = 文件不存在。**
- **干预端可复现**:claude 会话能按 session 明确打上 `skill_on` / `skill_off` 组标,且不污染 D1 计数流(不新增工具、不改现有调用折叠)。
- **测量端可复算**:当前自发率靠 D1 双标人工标注(正式 100 条:codex 66 任务/34 半自发,claude 79/19/2 被动),**不可在线复算、成本高**。→ 这正是 B10/B11 要补的。

**成本/代价:**
- 需要一段"冻结期"(期间不改干预与测量),窗口内活跃 session 仅个位数(9/2 观测:后窗口各不过数个)→ 需要**足够长窗口或跨多批**才能有统计意义。
- 强制 skill 对 claude 是行为侧改变(当前行为=自主/规则触发),一旦上 A/B 需保证不损伤正常任务产出。

## 6. 风险与边界

1. **Goodhart**:一旦"自发率"成为被考核指标,agent/人类会向"看起来自发"靠拢。→ 用**独立结果**(task done 率/done_gate reject/孤儿绑定率)作旁证,禁止只用"执行率提升"当成绩(9/2 已实锤循环论证)。
2. **样本过小 / 单 agent**:claude 单个案,窗口个位数 session,任何百分比都**只作参考,不作改善证据**(模板 §0 口径)。→ 需多批 + 报告置信度,勿下过头结论。
3. **auto 章污染**:任何用 `review_status`/`test_status` 当结果的口径必须**排除 `auto`**,否则重演执行组反而更低的假象。
4. **行为改造边界**:A/B 属行为改造,务必在冻结窗内不改其他行为杠杆;否则无法归因。**不做"先污染后审计"**(避免 LLM 自主解析产生归属缺口)。
5. **不重新定义北星指标**:D1 gold 100 条锁定不重算;双目标(纯自发线≈0%↑ + 含半自发线 15%→30%)分列报,禁止单一数字断言"达到 30%"(decision-334e73)。
6. **可发现性泄漏(off 形态)**:skill_off 若为"存在但关闭",agent 端仍可感知 skill 存在 → 对照组混入"不可见增量"。→ 按 §3 红线,**off = 文件不存在**。
7. **样本功效未量化(T2 待补)**:谁进 skill_on/off、任务类型(检索/写/引用)如何均衡、排除 `auto` 后个位数样本要达到 15%→30% 的 delta 需多少批次——需要先验功效估计(如两比例 z 检验的 n)。B10/B11 落地后,T2 设计需在此之前完成,不能等到开窗才拍。

## 7. 验收口径(路2 若执行,须按此报)

- **分列双目标**:纯自发率(≈0 起步,上升方向)+ 含半自发率(15%→30%),各自报实际值与趋势,不得合并。
- **独立结果**:task done 率 / done_gate reject / 孤儿绑定率正相关,且**排除 auto**。
- **排除 confound**:codex(无 skill)作为"可发现性对照组":若 skill 开的 claude 提升但 codex 同步,则仍是可发现性,不是强制。
- **合格门槛**:两批以上、报告置信度、同口径可比。
