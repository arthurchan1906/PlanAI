## 1. 定位（最终）

**AIPM = agent 的记忆层 / 事实层**：把 N 个 agent 各自「声称」做过的事，变成一份**可交叉核验的公共账本**。

三条硬边界：

1. **成败条件 = 取得回，不是记得全。** 写入侧已基本合格（hook 自动采集），全部剩余工作在检索侧。
2. **不能替 agent 记忆。** 记忆层是外部存储，不会让 agent 的上下文变大、也不会让它「想起来」。推论：「自发使用率」不是被砍掉，是**逻辑上不存在**。
3. **唯一不可替代性 = 声称 vs 实测并列可核验。** 「跨厂商」和「不依赖 agent 配合」都属易被替代（厂商做原生共享记忆即归零）。放弃核验，它退化成「一个能 grep 的日志库」。
